## 📖 Sobre o Projeto

Landing Page desenvolvida para apresentar informações, serviços e contatos de forma moderna, organizada e responsiva.

O projeto foi construído utilizando tecnologias web fundamentais, com foco em desempenho, experiência do usuário e adaptação para diferentes tamanhos de tela.

## 🚀 Demonstração

Acesse o projeto online:

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Vercel

## ✨ Funcionalidades

- Layout moderno e responsivo
- Navegação intuitiva
- Design adaptado para dispositivos móveis
- Estrutura otimizada para apresentação profissional
- Hospedagem online pela Vercel

## 🎯 Objetivo

Criar uma landing page profissional para apresentar o perfil, a trajetória e as qualificações da cliente nas áreas de Medicina Veterinária e Administração, facilitando o acesso às suas informações e contatos através de uma presença digital moderna e organizada.
